# 2-minute demo script
1. (0:00) Problem: mission design is complex and students rarely get to try it.
2. (0:15) Pick Mars + Discovery class, build a spacecraft, show the red alert, use Toolbox > LEARN hints to fix it.
3. (0:45) Launch: change material and weather, scrub the video, show the live charts. Press Record video.
4. (1:15) Toolbox > COMPARE against MAVEN, PLANNER for next Mars window, NASA LIVE for today's real data.
5. (1:45) SHARE link, then close with the data sources in the README.
